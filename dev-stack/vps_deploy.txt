# 3) Sua /etc/caddy/Caddyfile thanh:

sudo tailscale funnel --https=443 off

=====================================================================
TROUBLESHOOTING - cac loi DA TUNG GAP (va cach xu ly)
=====================================================================
* Build backend: "Package 'gpac' has no installation candidate"
    -> Dockerfile chua fix. Final stage phai FROM gpac/ubuntu (KHONG apt-get gpac).

* Build backend loi tai Bento4 (curl exit code 22 / 404)
    -> BENTO4_VERSION phai la  1.6.0-641  (dau CHAM), khong phai 1-6-0-641.

* Build backend loi dong "MP4Box -version && mp4decrypt --help"
    -> dong verify phai la:  RUN MP4Box -version && command -v mp4decrypt

* Frontend build: "tsc: Permission denied" (exit 126)
    -> thieu frontend/.dockerignore (phai loai node_modules; neu khong node_modules
       cua host de len de mat quyen +x cua tsc).

* /admin/wrapper: "kvs.sqlitedb not created" hoac "wrapper container missing"
    -> wrapper-data chua duoc seed. Chay lai lenh seed o PHASE 4.

* wrapper_state cu "unhealthy"/"failed" du container am-wrapper dang chay
    -> port wrapper bind 127.0.0.1 (chua fix). client.go phai bind 0.0.0.0.
       Sau khi fix: docker rm -f am-wrapper ; roi  up -d backend  (backend tao lai).

* redis: "failed to bind host port ... 6379 ... address already in use"
    -> co redis khac dang chiem cong. Doi REDIS_PORT=6380 trong .env.prod roi up -d.

* kong crash-loop "worker_events.sock: Address in use"
    -> tao lai container moi:
       docker compose --env-file .env.prod -f docker-compose.prod.yml up -d --force-recreate kong

* supabase-studio "unhealthy"
    -> vo hai. Frontend khong goi Supabase truc tiep; Studio chi la UI quan tri DB.
